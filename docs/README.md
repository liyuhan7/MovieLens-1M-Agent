# 文档导航

本项目为 MovieLens 1M 数据治理 Agent 系统：用真实 Hadoop MapReduce 清洗与评分，
用 LLM Agent 把流程串成自然语言可触发的链路，并提供可恢复任务、结构化产物与证据、
内容校验、唯一正式发布，以及正式结果查询、历史与版本比较、Hive 只读分析和备份恢复。

## 一句话速览

- **计算**：单 jar 内 9 种 MapReduce 作业，单次完整管线 12 次真实作业调用。
- **规则**：`rules-v2.0` / `metrics-v2.1`；规则与指标定义登记后不可原地改写。
- **身份**：输入数据版本、规则版本、指标版本、输出数据版本四条独立版本轴。
- **运行**：`ACCEPTED → QUEUED → RUNNING → VALIDATING → PUBLISHING → PUBLISHED`，重试新建 Attempt。
- **发布**：同一 Run 最多一个正式发布，current 独立更新且不被晚完成的旧 Run 覆盖。
- **解释**：报告数字、字段、证据引用必须匹配正式材料，推测单列并标注未验证。
- **实测**：users 6,946→6,112、movies 4,465→3,858、ratings 1,150,241→987,270，
  数据集综合分 93.33→99.98。
